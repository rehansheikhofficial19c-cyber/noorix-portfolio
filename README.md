# Noorix Digital Lab — Company Portfolio

A responsive, single-page corporate portfolio website for Noorix Digital Lab.

## Pages / sections
- Hero and company positioning
- Services: website development, custom software, AI chatbots, AI calling agents, mobile apps, business automation, UI/UX, cloud/backend/API
- About Noorix
- Technology capabilities
- Project delivery process
- Project inquiry form that opens WhatsApp with the submitted details
- Contact details and responsive navigation

## Stack
- Semantic HTML5
- CSS3 (responsive, no build step)
- Vanilla JavaScript
- Google Fonts (DM Sans and Space Grotesk)

## Run locally
Open `index.html` in a browser or use any static web server.

## Deploy
Can be deployed as a static site on Cloudflare Pages, GitHub Pages, or any standard web host. No build command is required; output directory is the repository root.

## Before production launch
- Confirm that the supplied company logo asset is the final official logo. The current header uses a text-based wordmark treatment and does not fabricate a logo image.
- Confirm all listed services and technology capabilities are currently deliverable.
- Add genuine project screenshots/case studies when approved assets and client permissions are available.
- Add an official business email if desired.
- Verify the target domain and hosting/deployment settings before publishing.
