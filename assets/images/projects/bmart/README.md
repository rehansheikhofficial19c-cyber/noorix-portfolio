# BMART project screenshots

Upload the BMART screenshots into this folder using these exact filenames so the Noorix portfolio can display them:

- `cover.webp` — main desktop homepage / hero screenshot (recommended 1600 × 700)
- `store.webp` — product catalogue or store page
- `mobile.webp` — mobile responsive screenshot
- `checkout.webp` — cart, order, or checkout flow

Use WebP or JPG. If you use JPG, either convert to the filenames above as `.webp` or update the image paths in `index.html`. Do not upload customer personal data, private order details, passwords, API keys, or payment information.

Live website: https://bmart.store
Project label: BMART — Digital Subscription Store
